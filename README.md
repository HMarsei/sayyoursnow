# sayyoursnow

**SAY YOURS — Say your sentence NOW!!!**

Static prototype for https://sayyoursnow.com

## Files

- `index.html` — main site
- `styles.css` — visual design
- `app.js` — interactions and demo flow

## Current status

This is a front-end prototype. The US$1 checkout buttons are demo buttons only.
Real payments, user accounts, database, permanent sentence numbers, likes,
comments, moderation and tags will be connected later.

## Deploy

Designed to be deployed with Cloudflare Pages from this GitHub repository.
